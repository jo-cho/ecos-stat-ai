# 경제통계 AI 검색

Streamlit에서 질문을 입력하면 MCP 도구를 통해 한국은행 ECOS 데이터를 조회하고 그래프·표·요약을 표시합니다.

## 실행

Python 3.11 이상에서 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

사이드바에 ECOS와 OpenAI API 키를 입력하세요. 연결 진단은 OpenAI 키 없이 실행할 수 있으며 주요지표와 통계표 목록 API를 모두 검사합니다.

## 이번 수정

- MCP 유지, 서버 내부 ECOS 클라이언트·HTTP 세션 재사용
- 통계표 목록을 임시 디렉터리에 24시간 캐시하여 질문 간 재사용. 인증키와 시계열은 캐시에 저장하지 않음
- 불완전한 목록과 실패 응답은 캐시하지 않음
- 항목은 요청한 개수만 조회하며 잘린 경우 truncated로 안내
- 시간 초과·연결 오류 및 HTTP 429/502/503/504에 기본 1회 재시도
- 질문에서 시간 초과가 두 번 발생하면 중단
- 모델 입력은 행을 줄여 유효 JSON으로 전달하며 화면 원자료는 유지
- 화면 장식과 HTML 표를 기본 Streamlit 구성으로 단순화
- 성공·부분 실패·실패 상태 구분

최초 목록 조회나 캐시 만료 후에는 실제 ECOS 연결이 필요합니다. 외부 서버 장애를 캐시와 재시도로 완전히 해결할 수는 없습니다. 항목이 잘렸다면 더 큰 limit(최대 300)으로 다시 조회하세요.

## 설정

아래 환경변수는 선택 사항입니다.

| 변수 | 기본값 | 의미 |
|---|---|---|
| ECOS_PAGE_SIZE | 500 | 페이지 행 수 |
| ECOS_MAX_ROWS | 3000 | 시계열·목록 조회 상한 |
| ECOS_CONNECT_TIMEOUT | 5 | 연결 제한(초) |
| ECOS_READ_TIMEOUT | 25 | 응답 읽기 제한(초) |
| ECOS_RETRIES | 1 | 재시도 횟수(0~2) |
| ECOS_CACHE_TTL | 86400 | 목록 캐시 유지(초), 0이면 재사용 안 함 |
| ECOS_CACHE_DIR | 시스템 임시 폴더/ecos-stat-ai | 목록 캐시 경로 |

기간 표시에는 기존 질문 해석 로직을 사용합니다. 복잡한 월·일 범위를 구조화하는 개선은 아직 포함하지 않았습니다. 실제 API 키로 배포 환경의 연결 진단과 질문 조회를 확인해야 합니다.
