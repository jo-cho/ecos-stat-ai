# 경제통계 AI 검색

자연어로 경제지표를 검색하고 한국은행 ECOS 데이터를 바탕으로 답변을 확인하는 웹 앱입니다. 브라우저에서 바로 이용하며, 별도 프로그램을 설치할 필요가 없습니다.

**[경제통계 AI 검색 바로가기](https://ecos-ai.streamlit.app/)**

## 주요 기능

- **자연어 검색**: 지표·기간·지역을 문장으로 입력해 경제통계를 조회합니다.
- **독립적인 검색**: 한 화면에 하나의 질문과 결과만 표시하며 이전 대화를 다음 검색에 전달하지 않습니다.
- **모델 선택**: 사이드바에서 제공하는 GPT 모델 중 하나를 선택합니다.
- **LLM 답변**: 질문에 맞춰 설명·수치·Markdown 표를 제공합니다.
- **원데이터 확인**: 버튼을 누르면 ECOS 원자료 표와 인터랙티브 그래프를 확인하고 CSV로 내려받을 수 있습니다.
- **관련 검색 추천**: 기간 변경·유사 지표·증감률 추가 등 밀접한 새 질문을 최대 3개 추천합니다.
- **조회 정보 접기**: 조회일·통계 코드·조회 조건·도구 호출 기록을 별도 영역에서 확인합니다.

## 이용 방법

1. [웹 앱](https://ecos-ai.streamlit.app/)에 접속합니다.
2. 사이드바에 본인의 **ECOS API 키**와 **OpenAI API 키**를 입력합니다.
3. 사용할 GPT 모델을 선택합니다.
4. 질문을 직접 입력하거나 질문 예시를 눌러 입력창을 채웁니다.
5. **검색하기**를 누르고 답변을 확인합니다.
6. 실제 조회 자료가 필요하면 **원데이터 확인하기**를 누릅니다.

추천 질문을 누르면 입력창에 문장이 채워집니다. **검색하기**를 눌러 독립적인 새 검색을 실행하세요. 새 검색을 실행하면 이전 결과는 교체됩니다.

### 질문 작성 예시

- 최근 3년간 한국은행 기준금리 추이를 알려줘
- 2025년 월별 소비자물가지수를 보여줘
- 2025년 월별 경상수지를 알려줘

지표명과 조회 기간을 구체적으로 입력하면 검색 범위를 좁히는 데 도움이 됩니다. 관측값의 시점은 API를 호출한 날짜와 다를 수 있습니다.

### API 키

- ECOS API 키: [한국은행 ECOS Open API](https://ecos.bok.or.kr/api/)
- OpenAI API 키: [OpenAI API 플랫폼](https://platform.openai.com/api-keys)

이 앱은 이용자가 입력한 키로 요청을 처리합니다. OpenAI API 사용 비용은 해당 키의 계정에 부과될 수 있으며, 선택한 모델의 사용 가능 여부는 계정 권한에 따라 달라집니다.

## 답변과 원데이터

통계 수치의 외부 출처는 **한국은행 ECOS Open API**입니다. LLM은 질문 해석, 도구 선택, 답변 및 추천 질문 생성에 사용됩니다.

기본 결과에는 LLM 답변만 표시합니다. 앱이 생성하는 원자료 표·그래프는 **원데이터 확인하기**를 눌렀을 때 나타납니다. 버튼을 눌러도 ECOS나 OpenAI API를 다시 호출하지 않습니다.

그래프는 조회한 원자료를 표시하며, LLM 답변에서 설명한 파생 증가율과 다를 수 있습니다. 자료가 없거나 날짜·수치 형식을 해석할 수 없는 경우에는 그래프가 표시되지 않을 수 있습니다. 서로 다른 단위의 계열은 구분해서 표시합니다.

LLM 답변에 오류가 있을 수 있으므로 필요한 경우 원데이터와 **조회 정보 및 출처**를 함께 확인하세요. 추천 질문은 검색 제안이며 해당 자료의 존재나 조회 성공을 보장하지 않습니다.

## Streamlit Community Cloud 배포

이 프로젝트는 GitHub 저장소와 연결해 Streamlit Community Cloud에서 배포합니다.

1. 프로젝트 파일을 GitHub 저장소에 올립니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에서 새 앱을 생성합니다.
3. 저장소와 배포할 브랜치를 선택하고 실행 파일을 **`app.py`**로 지정합니다.
4. Python 3.11 이상 환경을 선택하고 배포합니다.
5. 배포된 앱 URL을 이용자에게 공유합니다.

`requirements.txt`를 `app.py`와 같은 저장소 루트에 두세요. 현재 버전은 Matplotlib과 시스템 폰트 패키지를 사용하지 않으므로, 이전 버전의 `packages.txt`가 남아 있다면 제거하세요.

이용자는 화면에서 자신의 API 키를 입력합니다. 현재 코드는 운영자가 설정한 API 키를 자동으로 입력창에 채우지 않습니다. API 키를 소스 코드나 공개 GitHub 저장소에 넣지 마세요.

자세한 설정은 [Streamlit 공식 배포 문서](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app)를 참고하세요.

## 프로젝트 구성

| 파일 | 역할 |
| --- | --- |
| `app.py` | 검색 화면, 모델 선택, 추천 검색, 원데이터 표시 |
| `ecos_ai/agent.py` | OpenAI 도구 호출 루프와 답변·추천 질문 생성 |
| `ecos_ai/server.py` | ECOS 조회용 MCP 도구 서버 |
| `ecos_ai/ecos.py` | ECOS API 요청 및 응답 처리 |
| `ecos_ai/mcp_result.py` | MCP 결과 형식 정규화 |
| `ecos_ai/periods.py` | ECOS 주기별 시점 변환 |
| `requirements.txt` | Python 의존성 |
| `tests/` | API 응답 및 검색 화면 테스트 |

처리 흐름: **검색 입력 → LLM의 MCP 도구 선택 → ECOS 조회 → LLM 답변 → 선택적으로 원데이터 표시**

MCP 서버는 앱에서 서브프로세스로 실행하므로 별도 공개 MCP 서버를 배포할 필요가 없습니다.

## 화면 수정

- 처음 화면의 질문 예시: `app.py`의 `EXAMPLES` 목록
- 모델 선택 옵션: `app.py`의 `MODELS` 목록
- 대기 중 안내 문구: `app.py`의 `LOADING` 목록
- 답변 및 추천 질문 생성 기준: `ecos_ai/agent.py`의 `RULES`

질문 예시는 기본 화면의 3열 배치에 맞춰 3개로 유지하세요. 검색 후 추천 질문은 고정 예시와 별개로 LLM이 생성합니다.

## 연결 문제

ECOS 연결이 실패하면 잠시 후 다시 시도하고, 지속되면 Streamlit Cloud의 앱 로그를 확인하세요. API 키 오류와 서버 연결 시간 초과는 다른 문제입니다.

로컬에서는 성공하지만 Cloud에서는 실패할 경우 배포 환경에서 ECOS로 연결하는 경로에 문제가 있을 수 있습니다. 앱을 재시작해 다시 확인하되, 특정 원인을 단정하지 말고 오류 내용을 확인하세요. 로그를 공유할 때는 API 키와 키가 포함된 요청 URL을 제거하세요.

## 데이터와 키 처리

입력한 API 키는 현재 세션과 API 요청에 사용하며 앱 코드에서 별도 파일로 저장하지 않습니다. 다만 요청은 Streamlit 배포 서버를 거치므로 신뢰할 수 있는 운영자의 앱에서만 키를 입력하세요.

질문과 조회한 통계 자료는 답변 생성을 위해 OpenAI API에 전달될 수 있습니다. ECOS와 OpenAI의 이용 조건 및 데이터 처리 정책도 확인해 주세요.
