# 경제통계 AI 검색

처음 버전의 ECOS API·MCP 서버·패키지 설정을 유지하고 검색 화면과 답변 표시를 수정했습니다.

## 실행

Python 3.11 이상에서 프로젝트 폴더를 열고 실행하세요.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows에서 python 명령이 없다면 py를 사용하세요. Streamlit Cloud에서는 저장소 루트의 app.py를 실행 파일로 지정합니다.

## 사용

1. 사이드바에 개인 ECOS·OpenAI API 키를 입력합니다.
2. GPT 모델을 목록에서 선택합니다.
3. 질문을 입력하거나 예시를 눌러 입력창에 채웁니다.
4. 검색하기를 누르면 이전 결과를 교체합니다. 이전 질문은 모델에 전달하지 않습니다.
5. 대기 중 안내 문구가 순환합니다. 실제 세부 단계나 완료율을 나타내지 않습니다.
6. 답변·표·Matplotlib 정적 그래프를 확인하고 조회일·코드·조회 조건은 접힌 조회 정보 영역에서 확인합니다.

모델 옵션: GPT-5.5(기존 기본값), GPT-6.1 Sol, GPT-6 Luna, GPT-6 Astra, GPT-5 mini.
공식 모델 문서: https://developers.openai.com/api/docs/models
API 계정의 모델 권한에 따라 선택한 모델을 사용할 수 없는 경우가 있습니다.

관측 시점·항목·단위와 자료 부족·조회 실패 경고는 본문에 표시합니다. 조회 정보는 최종 모델 답변의 query_info와 실제 시계열 반환 메타데이터에서 가져옵니다. 모델의 JSON 출력이 깨진 경우 텍스트로 복구하며 조회 정보 행을 분리합니다.

경제통계는 ECOS 도구 결과에서만 가져옵니다. 입력 키는 파일에 저장하지 않습니다.

## 검증

```bash
python -m pytest tests -q
```

모의 API로 예시 입력·모델 전달·독립 질의·결과 교체·접힌 조회 정보를 확인합니다. OpenAI API 실제 모델 호출은 별도 키가 필요합니다.

그래프는 PNG로 다운로드할 수 있습니다. Streamlit Cloud에서는 packages.txt로 fonts-nanum을 설치하고 나눔고딕을 사용합니다. Windows에서는 설치된 맑은 고딕을 사용합니다.

## 관련 추천 검색

검색 결과에 독립적인 추천 질문 3개를 생성합니다. 지표·기간·지역을 명시하며, 기간 변경·유사 지표·적절한 증감률 추가를 추천합니다. 다른 지표와 비교하거나 이전 문맥을 참조하는 추천은 제외합니다. 클릭하면 입력창에 채워지며 검색하기를 눌러 새 검색을 실행합니다. 기존 질의는 모델에 전달하지 않습니다.

추천 질문은 최종 답변과 함께 생성하므로 별도 OpenAI 호출은 없습니다. 유효하지 않은 추천은 제외하므로 표시 개수가 3개보다 적을 수 있습니다.
